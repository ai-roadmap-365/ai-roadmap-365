Day 9 of 365 Days of AI — Navigating the Filesystem: Paths, Files, and Permissions

Move confidently through the filesystem tree, describe any location as an absolute or relative path, create and reshape files and directories from the command line, and read and set the read/write/execute permissions that decide who may do what.

What today covers:
→ Describe the filesystem as a single tree rooted at / and explain the meaning of the special path symbols /
→ Write both an absolute path and a relative path to the same file
→ Navigate and inspect the tree with pwd
