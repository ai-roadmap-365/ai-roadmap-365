Day 32 of 365 Days of AI — Remotes and GitHub

Connect a local Git repository to another copy of itself — a remote — and move commits between them with clone, fetch, pull, and push, understanding exactly what each does and how hosting platforms like GitHub build on top of that connection.

What today covers:
→ Define a remote as a named reference to another copy of a repository
→ Move commits between repositories with git clone
→ Explain what a remote-tracking branch (origin/main) is and how it relates to your local branch

The lab is the point: 30 minutes of hands-on work you run yourself, offline, with output you can check against a real captured run.
