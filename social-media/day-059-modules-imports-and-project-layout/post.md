Day 59 of 365 Days of AI — Modules, Imports, and Project Layout

Grow a program beyond one file: split a script into modules by responsibility, organize them into a package with an __init__.

What today covers:
→ Define a module as a single .py file and a package as a directory of modules marked by __init__.py
→ Use the three import forms
→ Explain what if __name__ == "__main__": does and why it lets one file be both a runnable program and an importable module
