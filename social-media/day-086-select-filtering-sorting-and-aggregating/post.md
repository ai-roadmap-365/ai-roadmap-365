Day 86 of 365 Days of AI — SELECT: Filtering, Sorting, and Aggregating

Read and write a full SELECT statement with the confidence that comes from knowing the order the engine actually runs it in — FROM, WHERE, GROUP BY, HAVING, SELECT, DISTINCT, ORDER BY, LIMIT — and to derive from that one ordering every rule that otherwise has to be memorised: why an aggregate is illegal in WHERE, why HAVING exists when WHERE already filters, and why ORDER BY may use an alias that WHERE cannot.

What today covers:
→ State the logical evaluation order of a SELECT and use it to predict which clause may refer to a stored column
→ Filter rows with comparison and boolean operators
→ Choose correctly between LIKE and GLOB

The lab is the point: 30 minutes of hands-on work you run yourself, offline, with output you can check against a real captured run.
