Day 23 of 365 Days of AI — REST Fundamentals: Resources and Verbs

Read almost any web API as a set of resources at addresses acted on by standard verbs, map CRUD onto HTTP methods, and reason about statelessness, idempotency, and good URL design — the architecture behind nearly every API you will ever call.

What today covers:
→ Define REST as an architectural style and explain the resource-and-verb model
→ Map the four CRUD operations onto the HTTP verbs GET
→ Explain statelessness and why it lets a REST service scale horizontally behind a load balancer

The lab is the point: 30 minutes of hands-on work you run yourself, offline, with output you can check against a real captured run.
