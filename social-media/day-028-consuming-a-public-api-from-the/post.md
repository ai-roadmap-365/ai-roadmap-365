Day 28 of 365 Days of AI — Consuming a Public API from the Command Line

Read an API's documentation and build a working client from scratch — form the request, send it with curl, parse the JSON reply, handle errors and rate limits, and present the result — the exact motion every AI API call needs.

What today covers:
→ Read API documentation and locate the four things every request needs: endpoint
→ Build and send a request from the command line with curl
→ Parse a JSON response for the fields you want using jq and python3

The lab is the point: 30 minutes of hands-on work you run yourself, offline, with output you can check against a real captured run.
