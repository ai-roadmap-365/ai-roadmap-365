Day 62 of 365 Days of AI — Recursion

Write correct recursive functions with a base case and a recursive case, picture how the call stack grows and unwinds and where RecursionError comes from, use recursion where it truly fits (walking nested lists, dicts, and trees), recognise why naive tree recursion like Fibonacci is exponential, fix it with functools.

What today covers:
→ Write a recursive function with a correct base case and recursive case
→ Trace the call stack for a recursion (e.g. factorial)
→ Use recursion for genuinely nested data

The lab is the point: 30 minutes of hands-on work you run yourself, offline, with output you can check against a real captured run.
