Day 60 of 365 Days of AI — A Tour of the Standard Library

After this lesson you will know the map of the Python standard library — which module to reach for by the shape of your need — and be able to build a real tool from pathlib, collections, datetime, and json alone, while exercising the judgement to prefer the standard library before adding a third-party dependency.

What today covers:
→ Explain what the standard library is
→ Reach for the right everyday module by need: pathlib for files and paths
→ Use collections.Counter

The lab is the point: 30 minutes of hands-on work you run yourself, offline, with output you can check against a real captured run.
