Day 11 of 365 Days of AI — Environment Variables and Shell Configuration

Read and set environment variables, explain how PATH decides which command runs, edit the correct shell configuration file for your shell, and keep secrets like API keys out of version control.

What today covers:
→ Distinguish a shell variable from an environment variable and explain what export does
→ Explain how the shell uses PATH to resolve a bare command name
→ Name and describe the most important environment variables
