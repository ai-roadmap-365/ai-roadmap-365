Day 75 of 365 Days of AI — Static Typing with mypy

Run a real type checker over your own code and act on what it says: you will explain the two-worlds model that Day 69 set up — annotations are inert at runtime, and a separate program reads them before anything runs — install and run mypy, read an error by its file, line, message and bracketed error code, recognise and fix the missing-None bug that a green test suite routinely misses, use Optional, Union, TypeVar, Protocol, Literal, TypedDict, Final, NewType and cast at the depth real code needs them, narrow a union with a guard so the checker follows your reasoning, demonstrate for yourself that Any silently switches checking off, configure mypy in a pyproject.

What today covers:
→ Explain the two-worlds model
→ Install mypy
→ Name and diagnose the five error codes that dominate real work

The lab is the point: 30 minutes of hands-on work you run yourself, offline, with output you can check against a real captured run.
