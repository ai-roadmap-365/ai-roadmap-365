Day 82 of 365 Days of AI — A First Web API with FastAPI

Stand on the other side of the wire: you will explain how a web API differs from a web page because the client is a machine and the contract therefore matters more than the appearance, describe REST honestly as a set of conventions from a dissertation rather than a standard you can comply with, build a FastAPI application with path parameters that convert, query parameters with defaults and constraints, and request bodies declared as pydantic models — and you will be able to say precisely why that last one is different from everything Days 69 and 75 taught, because an annotation now causes validation to happen at runtime against a stranger's data.

What today covers:
→ Explain what a web API is and how it differs from a web page
→ Describe REST accurately as an architectural style from Roy Fielding's 2000 dissertation rather than a standard
→ Build a FastAPI application: the app object

The lab is the point: 30 minutes of hands-on work you run yourself, offline, with output you can check against a real captured run.
