Day 49 of 365 Days of AI — Your First Real Program

Assemble a complete, small Python program from named functions, a main entry point, and the main-guard idiom — one that reads input, validates it, does one useful job, handles bad input gracefully, and can be tested.

What today covers:
→ List the five properties that make a program "real"
→ Explain what `if __name__ == "__main__":` does and why it lets a file be both a runnable program and an importable
→ Design a small program before coding it by listing its inputs

The lab is the point: 30 minutes of hands-on work you run yourself, offline, with output you can check against a real captured run.
