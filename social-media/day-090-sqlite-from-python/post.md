Day 90 of 365 Days of AI — SQLite from Python

Move a database from the shell into a program without acquiring either of the two failures that ruin real code: you will bind every value rather than building statements out of strings — having watched one apostrophe turn a lookup into a leak of every private record and then destroy a table, and watched the identical value become harmless the moment it is bound.

What today covers:
→ Demonstrate SQL injection rather than warn about it: build a query by concatenation
→ State precisely why binding works
→ Configure a connection deliberately: PRAGMA foreign_keys ON

The lab is the point: 30 minutes of hands-on work you run yourself, offline, with output you can check against a real captured run.
