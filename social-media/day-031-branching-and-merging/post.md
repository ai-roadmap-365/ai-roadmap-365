Day 31 of 365 Days of AI — Branching and Merging

Create and switch branches, merge them, resolve a merge conflict calmly, and explain when to merge versus rebase — the everyday loop for working on anything in parallel without breaking the version that works.

What today covers:
→ Explain what a branch is
→ Create and switch between branches with git branch and git switch (and the classic git checkout equivalents)
→ Distinguish a fast-forward merge from a three-way merge and identify which occurred from the history graph

The lab is the point: 30 minutes of hands-on work you run yourself, offline, with output you can check against a real captured run.
